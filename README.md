# 🌑 Portfolio Template - Dark Theme

Template portfolio pribadi modern dengan tema gelap yang elegan dan responsif.

Cocok digunakan untuk:
- Fresh graduate
- Junior Web Developer
- Frontend / Fullstack Developer
- Siapa saja yang ingin punya portfolio yang bagus dan siap pakai

---

## ✨ Fitur

- Desain modern dark theme
- Fully responsive (HP, tablet, desktop)
- Animasi scroll yang halus
- Loading animation
- Kartu proyek dengan tombol "Lihat Detail"
- Section kontak yang rapi
- Siap di-deploy ke GitHub Pages / Vercel / Netlify

---

## 🛠️ Tech Stack

- HTML5
- CSS3 (Custom Properties / CSS Variables)
- JavaScript (Vanilla)
- Google Fonts (Inter)

---

## 🚀 Cara Menggunakan Template Ini

1. **Fork** atau **Download** repository ini
2. Ganti data diri kamu:
   - Nama
   - Deskripsi tentang saya
   - Link proyek
   - Email, GitHub, dan LinkedIn
3. Upload ke GitHub
4. Aktifkan **GitHub Pages** (Settings → Pages → Deploy from main branch)

Selesai! Portfolio kamu sudah online.
